# TypeScript & OOP Assignment

## Overview

This repository contains my solutions for **Assignment 1: Problem Solving with TypeScript & OOP**. It covers core TypeScript concepts:

- Basic types, optional parameters, and rest parameters
- Union types and type narrowing with `typeof`
- Readonly tuples
- Interfaces
- Generics, including the `keyof` constraint
- Classes, inheritance, and access modifiers (`protected`, `private`)
- Promises and async functions
